# Edukind Charity Website

A simple responsive charity website concept focused on children and education.

## Pages
- `index.html` — Home page
- `about.html` — About Us page
- `styles.css` — Shared responsive styling
- `script.js` — Mobile navigation and current footer year

## Preview
Open `index.html` in a browser. No build step is required. Photos are loaded from Unsplash and will need an internet connection.

## Before publishing
- Replace the draft About Us story with verified information.
- Replace the example email with official contact details.
- Connect donation buttons to a secure donation service; they are placeholders at present.
- Add verified charity registration information, privacy policy, and real social links where appropriate.
- Do not publish unverified impact statistics.
